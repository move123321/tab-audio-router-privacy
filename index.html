Tab Audio Router 개인정보처리방침

Tab Audio Router는 Chrome 탭별 볼륨과 오디오 출력 장치를 제어하기 위해 아래 정보를 사용자의 기기에서 처리합니다.

탭 제목과 주소

열린 탭의 제목을 팝업에 표시합니다. 탭 주소는 제어 대상을 확인하고, 다른 출처로 이동하면 해당 탭의 오디오 제어를 종료하는 데 사용합니다. 방문 이력 목록은 저장하지 않습니다.

탭 오디오

사용자가 제어를 시작한 탭의 소리를 실시간으로 캡처하여 볼륨을 조절하고 선택한 출력 장치로 재생합니다. 오디오를 파일로 저장하지 않습니다.

출력 장치와 마이크 접근

선택 가능한 출력 장치를 조회합니다. 사용자가 추가 출력 장치 찾기에서 접근을 허용하면 권한 확인에 사용한 마이크 스트림을 즉시 종료합니다. 마이크 오디오는 저장하지 않습니다.

설정 보관

탭별 볼륨, 출력 장치 ID, 사이트 출처는 Chrome 세션 저장소에 보관합니다. 탭을 닫거나 다른 출처로 이동하면 해당 설정을 지우며, Chrome 세션이 종료되면 저장된 설정이 삭제됩니다.

공유 및 제한적 사용

위 데이터를 판매하거나 외부 서버 또는 제3자에게 전송하지 않습니다. Google API를 통해 받은 정보의 사용은 제한적 사용 요건을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 따릅니다.
